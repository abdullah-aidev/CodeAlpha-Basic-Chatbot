# 🤖 CodeAlpha Basic Chatbot

## 📌 About the Project

This is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Internship (Task 3).

The chatbot interacts with users through the terminal and provides predefined responses to different messages and commands.

## ✨ Features

* Responds to greetings such as Hello, Hi, and Hey.
* Supports Assalam-o-Alaikum and Salam greetings.
* Answers basic questions about itself.
* Displays the current time and date.
* Provides a help command to list available commands.
